# КАЛЬЯНЫ В НАЛИЧИИ
# Один кальян = одна строка. Части разделяйте палочкой |
#   Название | Цена | Имя файла фото | Короткое описание
#
# Пример (без решётки в начале строка появится на сайте):
#   Alpha Hookah Model X | 45000 | alpha-x.jpg | Нержавейка, высота 58 см, в комплекте чаша
#
# Фото загружайте в папку foto (там же, на GitHub). Имя файла латиницей, без пробелов.
# Если фото нет, оставьте это место пустым:  Кальян Y | 30000 |  | Описание
# Продали кальян? Просто удалите его строку.
# Строки, которые начинаются с #, сайт не показывает.
